# eGovernment.ai Standards

Welcome to the official repository for the **eGovernment.ai Standards Program (EGS)**.

This repository contains the authoritative specifications for:

- EGS — eGovernment.ai Standards Program
- CDF — Course Definition Framework
- OKF — Open Knowledge Framework
- LEONIDAS — Prompt & Agent Framework

The companion repository, **egovernment-ai-cdf**, contains the reference implementation, validators, builders, exporters, and sample courses.
