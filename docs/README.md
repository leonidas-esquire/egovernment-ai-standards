# eGovernment.ai Standards

Welcome to the eGovernment.ai Standards repository.

This repository contains the normative specifications, governance, architecture,
and conformance requirements for the eGovernment.ai family of open standards.

## Standards

- EGS — eGovernment.ai Standards
- CDF — Course Definition Framework
- OKF — Open Knowledge Framework
- LEONIDAS — Prompt & Agent Framework

## Repository Purpose

This repository contains specifications—not implementations.

Reference implementations live in their own repositories and conform to the
documents maintained here.
