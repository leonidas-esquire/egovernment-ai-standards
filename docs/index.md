# eGovernment.ai Standards

Welcome to the eGovernment.ai Standards Program.

This site publishes the official specifications for:

- EGS — eGovernment.ai Standards
- CDF — Course Definition Framework
- OKF — Open Knowledge Framework
- LEONIDAS — Prompt & Agent Framework

The standards are designed to help governments and public-serving organizations build trustworthy, governed, interoperable AI systems.
