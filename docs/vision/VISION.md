# eGovernment.ai Standards Vision

## Mission

Create open, vendor-neutral standards that enable governments and public-serving
organizations to build trustworthy, governed, interoperable AI systems.

## Principles

- Open by default.
- Human-readable.
- Machine-readable.
- Platform independent.
- Accessibility first.
- Governance before implementation.
- AI augments human expertise.
- Long-term interoperability.
- Security and responsible AI by design.
- Public benefit above vendor lock-in.

## Standards Family

EGS provides governance for:

- CDF
- OKF
- LEONIDAS

Each specification evolves independently while remaining interoperable through
shared principles and governance.
