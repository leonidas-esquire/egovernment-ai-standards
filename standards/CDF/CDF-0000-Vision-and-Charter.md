# Abstract

The Course Definition Framework (CDF) is an open, platform-independent specification for authoring, governing, validating, versioning, and publishing professional learning experiences from a single authoritative source.

CDF separates learning content from any individual Learning Management System (LMS), allowing organizations to create governed learning assets that can be published consistently across multiple platforms and formats.

---

# 1. Purpose

The purpose of the Course Definition Framework is to define a common, interoperable representation of professional learning that is independent of any specific Learning Management System, authoring platform, or publishing technology.

CDF enables organizations to author learning once and publish it many times while preserving governance, accessibility, traceability, and quality.

---

# 2. Mission

The mission of the Course Definition Framework is to provide an open, platform-independent standard for authoring, governing, validating, and publishing professional learning experiences from a single authoritative source.

---

# 3. Problem Statement

Many organizations maintain learning content inside proprietary Learning Management Systems, resulting in duplicated effort, inconsistent updates, limited portability, and vendor lock-in.

The rapid adoption of AI-assisted content generation introduces additional challenges. Learning content can now be produced at unprecedented speed, but often without consistent structure, governance, citations, validation, or version control.

CDF addresses these challenges by defining a platform-independent representation of governed learning.

---

# 4. Vision

The Course Definition Framework envisions a future in which governed learning is portable, interoperable, versioned, and trustworthy.

In that future:

- Governments publish CDF-compliant learning resources.
- Multiple LMS platforms support native CDF import and export.
- AI systems generate standards-compliant learning packages.
- Organizations exchange governed learning as easily as they exchange PDF documents today.
- Learning remains independent of any individual software platform.

---

# 5. Guiding Principles

CDF is founded on the following principles:

1. Knowledge should outlive platforms.
2. Learning should be governed.
3. Every learning objective should be measurable.
4. Every assessment shall align to one or more learning objectives.
5. Factual instructional content should support authoritative references where appropriate.
6. Accessibility is a design requirement.
7. AI augments authors but does not replace accountability.
8. Courses should be versioned using modern software engineering practices.
9. Open standards promote interoperability.
10. One authoritative source should produce many learning outputs.

---

# 6. Relationship to EGS

CDF is governed by the eGovernment.ai Standards Program.

All governance, lifecycle, versioning, and normative language are inherited from EGS-0000.

---

# 7. Relationship to OKF

The Open Knowledge Framework (OKF) governs authoritative knowledge.

CDF governs educational experiences derived from governed knowledge.

Where practical, CDF learning assets SHOULD reference authoritative OKF knowledge assets.

---

# 8. Relationship to LEONIDAS

LEONIDAS provides standards for AI-assisted authoring and interaction.

CDF defines the structure and governance of learning content.

Together they enable responsible AI-assisted course development.

---

# 9. Licensing Philosophy

CDF is published as an open specification.

Organizations are encouraged to implement CDF in commercial and open-source software.

Reference implementations, validators, builders, exporters, templates, certification programs, and enterprise tooling may be developed independently.

---

# 10. Long-Term Vision

CDF is intended to become a durable standard for professional learning that remains useful regardless of future Learning Management Systems, publishing platforms, or AI technologies.

Learning should remain governed, portable, interoperable, and trustworthy for decades to come.

---

# 11. Conclusion

The Course Definition Framework establishes the philosophical and governance foundation for all subsequent CDF technical specifications.

Future CDF specifications define how the framework operates.

This charter defines why it exists.
